# Synthesis: mesh-m3-docintel

Five personas (architect, engineer, compliance/DPO, ux, pm), 2026-08-22. The Sales seat was swapped for **Compliance/DPO** because M3's risk is data protection, not selling. Founder steer: build the whole project tonight, autonomous; no external access. Decisions: [[connector-access]], [[data-residency]].

## Unanimous / convergent (adopted)
1. **Extraction artifact is a side-car, not a fold event kind** (Architect). `lm.docintel.extraction/1` is a KNOWN artifact family but NOT a `KnownCaseLogEventKind` — feeding it to the fold quarantines it. State deltas ride as real case-log entries (`field-change`, `conflict-upsert`, `document-upsert`, `checklist-status`) each carrying `origin.artifactId` → the extraction side-car. Zero fold changes; genuinely additive.
2. **Determinism preserves the M1 refold invariant** (Architect). Conflict at 1% materiality is arithmetic over two Pence values → a **deterministic recompute** in `conflicts.ts`, NEVER an LLM-emitted `conflicts:[]`. The agent may propose attribution *features*; the 0.85 attribution gate stays deterministic. Otherwise refold-byte-equality (M1 SC) breaks.
3. **Idempotency by content, not attempt** (Architect, engineer — must-not-ship-without). The fold dedupes only at log level (seq/watermark); re-processing a doc mints new seqs → double-writes, and `directiveIdentity` includes `attemptNonce` so dispatch won't dedupe either. **Every id M3 derives (conflictId, worklistId, field-change target) MUST be a pure function of `(documentId, contentHash, fieldKey)`.**
4. **Quote-locator is a coded substring match against an INDEPENDENT text layer, not a non-empty check and not prompt-only** (Architect, engineer). Today `DocInsight.sourceQuote` is optional, there's no locator field, and `applyFieldChange`/`casesStore` default `src ?? 'det'` — so absence silently yields `det`. M3 MUST: add a locator field; in `extractionApply` do a deterministic substring match of the claimed quote against born-digital PDF text; **match ⇒ `det`, else `syn`**; flip the default so unverified ⇒ `syn`. Vision-only/scanned (no independent text layer) ⇒ **always `syn`**.
5. **The ingest upload seam is net-new** (engineer). `FileAttachment → transport.uploadAttachment(projectId) → artifact_id → directive.inputs.artifacts[] → submitCommand(attachment_ids)` — nothing bridges this today; it's Phase-1 work, not an assumption. (Also corrects the arch doc's "reuses F01 materiality" — the store/fold plumbing exists, the 1% computation is net-new.)
6. **Red-team targets the WRITE path, not just send** (Compliance, engineer). Beyond "content is data / no-send-path": a crafted doc can forge a matching quote+locator to plant a false `det`, or steer attribution to leak applicant A's PII into B. The malicious-doc corpus MUST assert: no `det` without a verifiable independent-text match, no cross-applicant attribution leak, no conflict suppression, and no outbound artifact. Extraction output is a **closed typed schema**. CI = fixture bytes + stubbed model asserting these invariants (no live model/network); live-model behavioural evals are nightly.
7. **Precision is per-field, and income is special** (Compliance, pm). An aggregate ≥0.95 can hide ~0.80 on income (gross vs net, YTD vs monthly) — a suitability breach (MCOB 11.6.8R). Publish **per-field** precision; **income stays adviser-confirmed at G9 regardless of score**; a `syn` income field NEVER satisfies G9.
8. **Gate the accuracy bar in two** (pm). Synthetic + write-path red-team = **hard merge/demo blocker tonight**; the ≥0.95-on-≥50-real-docs bar gates only the **external accuracy claim + G9 autonomy**, not the build. Owner of the real corpus = design-partner #1 (a founder input, like credentials).
9. **Data residency** (Compliance — hardest blocker): build on synthetic/redacted tonight; real PII gated on inference location + IDTA (see [[data-residency]]). Special-category + out-of-scope docTypes gated (flag/quarantine). Per-docType retention; store the located line; crypto-erase raw statements once `det`.
10. **UX: trust is shown, not asserted** (ux). Pessimistic extraction (facts appear only on fold); DocCard `QUEUED→PROCESSING→COMPLETED`; a `det` fact **deep-links to the highlighted quote span** in the preview (a locator string isn't trust); `syn` carries a **non-color channel** (label + confidence e.g. `syn · 0.62` + confirm) because det→emerald/syn→violet is an adjacent-hue/dark-contrast trap; G2 shows the extracted identity beside both candidate applicants (decide without opening the doc); G3 is two-column existing-vs-new with the delta, loser retained (record-never-repair); unmapped insights collapsed (no fact-find dump); G9 shows **why** it's blocked, tied to the specific unverified income field; typed error cards for garbled/oversize + low-OCR; aria-live on completion, provenance in the accessible name not color.
11. **Downstream freeze** (pm, architect). `lm.docintel.extraction/1` + the det/syn+hint field provenance is frozen and documented as the fact-find's source of truth, so M4/M5 (sourcing/criteria) read it without rework.

## Tradeoffs — RESOLVED
- **Accuracy gate**: split (synthetic+red-team hard blocker; ≥0.95-on-real gates the claim + G9 autonomy). 
- **Data residency**: synthetic/redacted build tonight; real PII access-gated ([[data-residency]]).
- **OCR path**: model-vision v1, measured against per-field F1; born-digital text is the independent layer for the det substring match; vision-only ⇒ syn.
- **Deferred (not M3 build inputs)**: the ≥50 real-redacted corpus owner+date; the inference-location/IDTA confirmation. Both founder/infra inputs.

## Acceptance criteria (union)
- A doc dispatched via the net-new ingest seam produces an `lm.docintel.extraction/1` side-car + case-log `field-change`/`conflict-upsert`/`checklist-status` entries (with `origin.artifactId`) the M1 fold ingests — and re-processing the same doc is idempotent (content-derived ids).
- Every written `det` field has a verifiable independent-text quote+locator; unverified/vision-only ⇒ `syn`; the `src ?? 'det'` default is flipped.
- Conflict materiality is a deterministic Pence recompute; the d7 £38,500/£37,300 case fires G3; refold stays byte-identical (M1 SC-004 holds with docintel entries).
- Attribution <0.85 or joint ⇒ G2 (deterministic gate); income `syn` never satisfies G9; G9 shows the blocking field.
- Write-path red-team corpus passes as a hard CI gate (no false det, no attribution leak, no suppression, no outbound); extraction schema closed.
- Per-field precision published; special-category + out-of-scope docTypes gated.
- Doc vault: DocCard state machine, det deep-links to the highlighted span, syn non-color + confidence + confirm, G2/G3 decidable without opening the doc, typed error states, aria-live.
- All existing tests green; new UI passes design-token + i18n parity; vitest baseline unmoved.

## Out of scope (M3)
Live real-client-PII processing (access-gated); connectors; sourcing/criteria/affordability; the client portal; live agent dispatch. Develops against frozen M2 contracts; only the doc-vault verification surface needs M2 merged.
