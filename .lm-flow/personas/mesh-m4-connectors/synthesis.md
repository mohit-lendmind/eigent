# Synthesis: mesh-m4-connectors

Five seats (architect, engineer, compliance, ux, head-of-sales), 2026-08-22. The panel caught two load-bearing errors in the architecture doc (the `lb4Driver` wrapper and "API-intercept-first"), corrected below. Decisions [[connector-access]], [[data-residency]] bind. Founder steer: build the framework + connectors for all broker tools (framework supports all; v1 ships two); build on Opus 4.8, gate on Fable 5.

## Convergent / adopted (code-grounded)
1. **No callable "lb4Driver" — `buildQuery` is a declarative directive plan the model runs** (architect + engineer, from `browserDelegationExecutor`/`agentBrowser`). The executor is a renderer-side pump fed only by `aionChatBridge.onState`, driving `browser_*` calls the cloud model already parked. So the adapter emits a plan; the agent loop + delegation pump execute it via `lm.directive/1`; "the driver" is really per-firm `browser_session_mode` config. No synchronous browser RPC; no new M1 coupling.
2. **"API-intercept" only works for public MSE** (architect + engineer, from `CDP_ALLOWED` — no Network/Fetch domain; `browser_console_exec` blocked in `logged_in`). MSE (isolated, public) reads JSON via a console fetch; **every licensed (logged-in) adapter is structurally DOM-scrape only** — no network interception exists. The durability story holds for MSE; licensed adapters are inherently more brittle. State it honestly.
3. **Record/replay = capture `tool_result` SSE `{tool_name, arguments_json, result_json}` and feed `result_json` to a PURE `extract()` in vitest** (engineer) — no browser/login/model, CI-able. Do NOT copy `halifax.eval.ts` (live, needs bootstrap+edge+model). **Replay guards our extract regressions only; a LIVE canary (MSE only) catches portal drift** (architect corrects the doc's "replay catches drift"). Licensed adapters have no drift detection until access — recorded, not live.
4. **A full result set (~1,746 products) is silently dropped by the fold** (architect, from `foldSource` oversize→skip). The snapshot case-log entry MUST be a small **folded summary**; the **full set rides as a referenced attachment**, not inline.
5. **`decodeSourcingSnapshot` validates only the spine** (engineer) — it accepts a snapshot with no coverage/products/verified. M4 needs a **dedicated payload decoder** requiring `coverageStatement`, `ratesAsAt`, `products[]` (full incl. declines), `verified`.
6. **`verified` is not a self-asserted boolean** (architect + engineer + compliance). Derive it from `verificationRef + fixtureHash + ratesAsAt + raw-enquiry-evidence pointer`; enforce via a single **`assertClaimable(snapshot)` choke-point** the results surface AND every evidence export MUST call — in the writer/fold, not UI hiding. Convention won't hold an FCA invariant.
7. **Invariant 2 (no steering) needs a structural control, not prose** (compliance): a `surfaceClass:"adviser-only"` tag on every sourcing snapshot + a **CI test** proving no client-facing component (A1 portal, A7 comms) can decode/embed it (PERG 4.6.16A/4.6.25B — a client-reaching agent-ranked list = making arrangements / unapproved promotion).
8. **Invariant 4 (coverage integrity)**: coverage is a typed enum + machine-checkable **`wholeOfMarket:boolean`**; a **lint gate** rejects the literal phrase "whole of market" unless the flag is true (MCOB 4.4A.4R(3)/4.4A.1R); the statement is **copied into** every snapshot/shortlist/evidence pack, never a driftable pointer.
9. **Evidence-of-research (MCOB 4.7A.9R)**: the full set incl. declines + rates-as-at is the right spine; stamp **adviser id, ratesAsAt, coverage, verified** on every snapshot; **G5 staleness warning** when rates-as-at is old.
10. **Automation under the adviser's login**: written per-portal ToS confirmation before each licensed adapter builds (spec §8.2 [VERIFY]); the adviser is **accountable as principal** (SYSC 8 doesn't transfer liability; SM&CR); every automated action stamps the acting adviser id + take-control availability.
11. **Local sourcing serialized per desktop** (engineer): `AgentBrowser` is a singleton (one window, one `logged_in` partition) — two cases sourcing at once thrash it. Single-tenant-per-desktop must be stated.
12. **UX for the computer-use moment** (ux): a **narrating step ribbon** ("Entering income £48,200 · reading 34 products") + an always-hot, never-modal **Take control** that freezes mid-step and yields the live cursor + a **"Running as you"** login label. Shortlist = ranked **cards** (lender, monthly, one true-cost number, Why?), rejected lenders collapsed under "N not shortlisted" each expanding to one plain sentence. Coverage line **pinned to the header**, info tone, never red, non-dismissable. `verified:false` = watermark band + "Not for client use — awaiting verified feed" with export / add-to-suitability **disabled**, not just labelled. **G5** stays disabled until the adviser picks a product AND types a one-line rationale (choice + rejected-reasons snapshot fold).

## Tradeoffs — RESOLVED
- **v1 adapters** = `mse` (verified) + `mortgage-brain` (scaffold, `verified:false`) — reconciles the architecture doc (which listed four) with spec §4-A4/§12 (two). **The framework supports all broker tools** (27Tec, Mortgage Magic, etc. plug onto the same interface); v1 *ships* two. Directly answers the founder's "connectors for all of them": the framework is the all; adapters are incremental.
- **MSE = isolated/console-fetch; licensed = logged-in/DOM-scrape**; no adapter claims API-intercept beyond MSE.
- **Snapshot = folded summary + attachment** for the full set.
- **verified = derived + assertClaimable choke-point**, enforced in the writer.
- **Deferred (not M4 build inputs)**: which licensed tool is design-partner #1's (founder input — gates the first *real* recorded session + a paid reference); per-portal ToS confirmation per licensed adapter; `writeBack`/DIP (no browser-action idempotency key yet → out of the M4 interface until G8/M-late).

## Acceptance criteria (union)
- An adapter emits a declarative plan run via `lm.directive/1`; the sourcing run writes a **folded-summary** case-log entry + a **full-set attachment** + an immutable `lm.sourcing.snapshot/1`, all ingested by the fold (no oversize drop).
- The dedicated payload decoder rejects a snapshot missing coverage/ratesAsAt/products/verified.
- `assertClaimable` blocks a `verified:false` (or evidence-less) snapshot from the results surface, any evidence-of-research export, and any client surface — test-covered in the writer/fold.
- MSE adapter verified by a **pure recorded-replay** in CI + a live canary for drift; licensed scaffolds ship `verified:false` with authored (not-green) replays that go green on a real recorded session.
- Coverage `wholeOfMarket:boolean` + lint gate on the literal phrase; the statement is copied into every artifact; surfaces never exceed it.
- `surfaceClass:"adviser-only"` + a CI test that no client-facing component can embed a sourcing snapshot.
- The results shortlist renders ranked cards + collapsed why-not + pinned coverage line; the computer-use run shows the narrating ribbon + always-hot take-control + "Running as you"; G5 requires pick + rationale.
- Local sourcing serialized per desktop; fixtures scrub session tokens/CSRF/PII; every automated action stamps adviser id.
- M1 kill-the-laptop convergence holds with sourcing entries; all gates green; dark-mode contrast verified (don't trust forced-light Storybook).

## Out of scope (M4)
Live licensed adapters (access-gated, verified:false until a real recorded session); `writeBack`/DIP submission (→ G8/M-late, needs a browser-action idempotency key); client-facing sourcing (forbidden by invariant 2); >2 adapters shipped (framework supports them; v1 ships mse+mortgage-brain).

## User Journeys
### J1 — Watch it source MSE, live, under your login
Adviser triggers sourcing on a fact-find-complete case → the visible browser drives MSE (isolated) with a narrating ribbon + always-hot take-control → full result set + coverage line captured → immutable snapshot in the audit file; ranked cards shown, adviser-only.
Success: plan runs via directive; snapshot folds (summary + attachment); coverage pinned + honest; take-control freezes mid-step; nothing client-facing.
### J2 — The scaffold is honestly not-live
Adviser (design partner) selects Mortgage Brain (scaffold) → results render watermarked "Not for client use — awaiting verified feed"; export + add-to-suitability disabled; `assertClaimable` blocks any evidence use.
Success: verified:false is enforced in the fold, not just UI; a scaffold can never enter an MCOB 4.7A record.
### J3 — The evidence-of-research pack
From a verified MSE snapshot → an evidence export carries the full set incl. declines, rates-as-at, coverage statement, adviser id, verified — and refuses if the snapshot isn't claimable.
Success: MCOB 4.7A spine present; assertClaimable gates the export; coverage never overclaimed.
